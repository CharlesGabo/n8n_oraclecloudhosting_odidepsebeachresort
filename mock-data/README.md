# Mock Resort Knowledge Base

This directory contains fictional training data for learning and testing the n8n
Messenger support workflow. **Seabreeze Cove Resort does not represent a real
business.** Never publish its prices, contact details, policies, or availability
as factual information about a real resort.

Files:

- `seabreeze-resort-faq.md`: readable FAQ and staff reference.
- `seabreeze-resort.json`: structured data suitable for n8n expressions or a
  future retrieval pipeline.
- `gemini-system-prompt.md`: grounded support-agent instructions.
- `test-cases.json`: expected behavior tests for the workflow.

When a real resort is available, replace the mock data, review every policy with
the owner, and rerun all test cases before activating Messenger replies.
